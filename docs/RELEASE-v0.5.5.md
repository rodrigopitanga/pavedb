# PatchVec 0.5.5

## English

PatchVec 0.5.5 improves ingestion, search results, and release tooling.
PatchVec is now PaveDB.

### Highlights

- Adds CSV controls for headers, metadata columns, and included columns.
- Makes re-ingest behavior deterministic with default document IDs and fixes
  authentication edge cases.
- Initializes FAISS-backed collections on creation and returns original text
  with search results.
- Adds an end-to-end Makefile target and improves Docker and PyPI release
  automation.
