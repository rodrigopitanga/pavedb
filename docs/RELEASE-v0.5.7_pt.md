# PatchVec 0.5.7 — Readiness

## Português (Brasil)

PatchVec 0.5.7 adiciona recursos de prontidão operacional para backup, busca e
observabilidade. O PatchVec agora é o PaveDB.

### Destaques

- Adiciona fluxos de exportação e restauração do armazenamento em arquivos ZIP
  pela API e pela CLI.
- Adiciona motivos de correspondência aos resultados de busca, logs de
  requisições estruturados e histogramas de latência para busca e ingestão.
- Define um modelo de embeddings multilíngue como padrão e adiciona um
  benchmark de estresse concorrente das operações de API suportadas.
- Melhora escritas atômicas, a persistência de métricas e os alvos Makefile de
  benchmark.
