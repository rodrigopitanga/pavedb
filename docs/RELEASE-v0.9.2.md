# PaveDB 0.9.2

## English

PaveDB 0.9.2 adds more flexible ingestion, configuration, and reference
material for operators and library users.

### Highlights

- Adds batch and JSON document ingest.
- Centralizes the configuration schema, adds an embedder registry and inventory
  endpoints, and improves production-ready configuration defaults.
- Adds an embedded/library-mode client alongside the service API.
- Publishes generated CLI reference material, a store protocol guide, and an
  OpenAPI contract snapshot.
- Adds HTTP request metrics middleware and improves startup and file logging.
