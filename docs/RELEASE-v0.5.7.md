# PatchVec 0.5.7 — Readiness

## English

PatchVec 0.5.7 adds operational readiness features for backup, search, and
observability. PatchVec is now PaveDB.

### Highlights

- Adds ZIP datastore dump and restore workflows through the API and CLI.
- Adds match reasons to search results, structured request logging, and latency
  histograms for search and ingest.
- Sets a multilingual embedding model as the default and adds a concurrent
  stress benchmark across supported API operations.
- Improves atomic writes, metrics flushing, and benchmark Makefile targets.
