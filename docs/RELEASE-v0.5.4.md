# PatchVec 0.5.4

## English

PatchVec 0.5.4 is the initial public release of a multi-tenant, pluggable
vector-search microservice. PatchVec is now PaveDB.

### Highlights

- Introduces the public service for multi-tenant vector search.
- Establishes pluggable vector search as the project's core model.
