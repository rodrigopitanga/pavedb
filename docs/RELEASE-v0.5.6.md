# PatchVec 0.5.6

## English

PatchVec 0.5.6 strengthens ingestion, operations, and packaging. PatchVec is
now PaveDB.

### Highlights

- Adds ingestion timestamps and expands CSV controls for headers, metadata, and
  included columns.
- Hardens service startup with clearer configuration, binding, and
  authentication safeguards.
- Makes multi-document FAISS ingest safer and improves store concurrency and
  text hydration.
- Expands Docker CPU/GPU release flows and adds a lightweight Swagger/OpenAPI
  interface.
