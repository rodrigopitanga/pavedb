# PatchVec 0.5.4

## Português (Brasil)

PatchVec 0.5.4 é a primeira versão pública de um microsserviço de busca
vetorial multi-tenant e plugável. O PatchVec agora é o PaveDB.

### Destaques

- Apresenta o serviço público para busca vetorial multi-tenant.
- Estabelece a busca vetorial plugável como o modelo central do projeto.
