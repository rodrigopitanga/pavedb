**Binary wheels.** Some wheels (e.g. `torch`, `scipy`, `numpy`, `faiss-cpu`) bundle third-party runtime components (BLAS/LAPACK, compiler runtimes) under their own licenses. The `-cpu` image carries none of NVIDIA's CUDA stack; the `-cuda` image, published best-effort for final releases, additionally pulls torch's Linux-only CUDA dependencies — the `nvidia-*` runtimes (NVIDIA proprietary) and `triton` (MIT). Distributed images keep each package's `*.dist-info` directory (license/NOTICE files) so those terms travel with the binaries.
